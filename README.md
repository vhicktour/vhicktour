## About

I'm a full stack software engineer with 5+ years in software development and cybersecurity. I build web apps with Python, Java, React, and Next.js, and I add AI features to them with Amazon Bedrock and the OpenAI API.

I build software for a federal agency. Before that, I built an AML screening pipeline for a fintech platform and shipped AI chatbots and web apps for small business clients.

I served in the U.S. Navy from 2019 to 2024 as an Operations Specialist, then in the Air Force Reserve. I hold an active DoD Secret clearance and CompTIA Security+.

## Focus

- LLM features with Amazon Bedrock (Claude) and the OpenAI API, including RAG and GraphRAG chatbots that answer from company data
- REST and GraphQL APIs in FastAPI, Spring Boot, NestJS, and Node.js
- React and Next.js front ends written in TypeScript
- PostgreSQL schemas and Neo4j knowledge graphs
- AWS infrastructure in Terraform, including Lambda, SQS, SNS, and S3
- Docker containers and GitHub Actions CI/CD
- Playwright end-to-end test suites
